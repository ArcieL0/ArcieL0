## 🚀 Proyek Pilihan

### 🧠 Klasifikasi Distorsi Kognitif melalui Teks
> *Academic Project · NLP*

Membandingkan performa **SVM (TF-IDF)**, **BiLSTM**, dan **IndoBERT** untuk mendeteksi distorsi kognitif dari teks berbahasa Indonesia, dengan preprocessing menggunakan **Sastrawi**.

| Model | Pendekatan |
|:------|:-----------|
| SVM | Fitur TF-IDF |
| BiLSTM | TensorFlow / Keras |
| IndoBERT | Fine-tuning dengan Hugging Face Transformers + PyTorch |

- 📊 **Evaluasi:** F1, precision, recall, dan cross-validation
- 🏆 **Hasil:** IndoBERT jadi model terbaik dengan **F1 rata-rata 74.62%**

📩 Materi proyek tidak dipublikasikan secara terbuka. **Hubungi saya** lewat email untuk mendapatkannya.
